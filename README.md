# Stream Recorder – Multi‑Stream Bash Script (yt-dlp + ffmpeg)

Ett enkelt och flexibelt Bash‑script för att spela in flera livestreams samtidigt från tjänster som stöds av **yt‑dlp**.  
Projektet är skapat som ett inlärnings- och experimentprojekt och är helt gratis att använda, modifiera och dela.

Detta projekt innehåller kod som har genererats med hjälp av AI‑verktyg Google Gemini Ai.
All kod har granskats, testats och modifierats manuellt av mig.

## ✨ Funktioner

- Spela in en eller flera livestreams parallellt
- Manuell/Automatisk hantering av filnamn och mappar
- Använder yt-dlp för stream‑hämtning
- Använder ffmpeg för stabil inspelning
- Använder text-fil konfiguration – kör direkt från terminalen

## 📦 Krav

Du behöver följande installerat:

- **yt-dlp**
- **ffmpeg**
- **bash** (Endast testat på RaspOS)

Installera med RaspOS

```bash
Installera yt-dlp:
sudo apt install yt-dlp
Installera ffmpeg:
sudo apt install ffmpeg
```
